# Third-party skills

## designer-skills (Julian Oczkowski)

`brief-to-tasks`, `design-brief`, `design-flow`, `design-review`, `design-tokens`,
`frontend-design`, `grill-me`, and `information-architecture` are copied unmodified
from <https://github.com/julianoczkowski/designer-skills> at commit
`c259656c76d9758d7ead46b0d2f125cbe84f8665`, under the Apache License 2.0
(`LICENSE.txt` in each skill). Only the `SKILL.md` files were taken; the upstream
plugin manifest, README, and images were not.

Reviewed before import: instructions only, with no scripts, executables, hooks, MCP
servers, tool-permission frontmatter, hidden Unicode, or HTML comments. The only URL
in the skills is a `http://localhost:3000` example. `design-review` uses a browser
MCP server when one is available and otherwise asks for screenshots. The skills
write their artifacts under `.design/` in the project.

To update, re-review the upstream diff and copy the changed `SKILL.md` files.

`frontend-design` replaces the earlier Anthropic-derived skill of the same name.
